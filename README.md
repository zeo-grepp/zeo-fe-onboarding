### 과제를 모두 작성하신 후 아래 질문에 답변해 주세요

1. 작성한 과제의 구성요소, rules, design pattern에 대해 설명해 주세요.

**구성요소 (src 하위 폴더 구조)**

- assets: 정적 파일
- components: 재사용 UI 컴포넌트
- composables: 재사용 로직 컴포넌트
- constants: 상수 관리
- mocks: MSW 데이터 및 핸들러
- router: 라우팅 처리
- utils: 공통 유틸 함수
- views: 라우팅 단위의 페이지 컴포넌트

=> `npm create vue` 명령어로 시작한 프로젝트의 기본 구조를 참고

<br />

**rules**

- 도구 기반
  - tsconfig.json 옵션을 통한 타입 스트립트 강제 규칙
  - (eslint 설정도 추가했어야 했는데..)
- 수동
  - 함수는 화살표 함수로 작성
  - color값은 base.css에 변수화해서 사용
  - 상수값은 constants에 정의해서 사용

<br />

**design pattern**

- Composable 패턴으로 상태와 액션 분리 (useFetch/useMutation)

<br />

3. 과제를 진행하면서 사용한 라이브러리가 있다면 해당 라이브러리를 사용한 이유를 작성해 주세요. 없다면 없는 이유에 대해 작성해 주세요.

**추가한 라이브러리**

- vue-router: 라우팅 처리를 위해
- vitest, happy-dom: 테스트 코드를 위해

<br />

**axios, pinia 등의 라이브러리를 추가하지 않은 이유**

- axios: 과제의 규모상 fetch로 처리해도 충분하다고 판단
- pinia: 전역 상태로 관리할 필요가 있는 상태를 발견하지 못했기 때문
